# web

Веб-приложение Verner: карта активных пожаров, единый календарь пожаров по данным MODIS и VIIRS и помощник, который читает те же числа. React 19, TypeScript (strict), Vite.

Приложение только показывает данные и отправляет действия. Каждое число приходит из API (`../api`), здесь ничего не считается.

## Запуск

```sh
pnpm install
pnpm dev        # http://localhost:5184, /api идёт на http://127.0.0.1:8026
```

Сначала запустите API (`make run` в `../api`): без него нет данных. Карта, вкладки и панели открываются и так.

## Проверка

```sh
pnpm check      # типы, линтер, формат, тесты, сборка
pnpm test       # только Vitest
pnpm format     # Prettier, переписывает файлы
```

## Типы API

Типы берутся из `../api/openapi.json`. Их генерируют, руками не пишут:

```sh
pnpm api:types   # переписывает src/api/schema.d.ts
pnpm api:check   # падает, если schema.d.ts не совпадает с тем, что даёт текущий openapi.json (входит в pnpm check)
```

## Сквозные тесты

```sh
pnpm e2e        # Playwright смотрит на запущенное приложение
```

Тесты ничего не поднимают сами. Сначала запустите API на :8026 (`make run` в `../api`) и `pnpm dev` на :5184. Тесты открывают `http://localhost:5184` и работают на настоящих ответах API.

Нужно: Google Chrome. Без Chrome: `pnpm exec playwright install chromium`, затем `E2E_BUNDLED=1 pnpm e2e`.

Playwright не сохраняет скриншоты, видео и трассировки. Проверка доступности запускает axe (WCAG 2.1 A и AA) на основных экранах.

## Другой API

`SENDA_API=http://host:port pnpm dev` направляет сервер разработки на другой API.

## Устройство

| Папка          | Что внутри                                                                            |
| -------------- | ------------------------------------------------------------------------------------- |
| `src/ui`       | Общие компоненты: меню, переключатель, плитки, подсказка графика, уведомление, иконки |
| `src/layout`   | Оболочка: верхняя панель, доска, чат, карта                                           |
| `src/features` | Доска, календарь, карта, пожары, чат, погода, климат, выбор региона, шкала времени    |
| `src/i18n`     | Тексты на английском, испанском, французском и русском                                |
| `src/styles`   | Токены дизайна и базовые стили                                                        |

## Заметки

- TypeScript 6.x, а не 7: typescript-eslint пока не работает на 7. Перейти на 7, когда заработает.

## Настройки

- Язык: меню настроек (шестерёнка). Пока язык не выбран, берётся язык системы; выбор хранится в браузере.
- Токены дизайна лежат в `src/styles/tokens.css`. Компоненты читают их и не держат своих цветов.
